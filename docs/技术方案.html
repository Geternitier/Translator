需求与交互

入口触发和显示完成条件
托盘 · 选区翻译读取稳定选区。Zotero 和 SumatraPDF 在必要时读取可复制选区并恢复剪贴板。译文在选区旁逐步显示。当前浮层可拖动。下一次选区重新定位。
Ctrl + Alt + O一次框选后持续识别。边缘拖动，角落缩放，悬停显示暂停和关闭图标。译文窗位置可拖动并保存。相同文字沿用当前译文。新文字取消过期翻译，确认空白后清除译文。
托盘选择音频程序或 Ctrl + Alt + S采集程序及其子进程的音频。即时译文流式更新，空档用相邻原文修订字幕。标题栏用于拖动，会话重开时恢复位置。可回看最近的字幕，支持双语显示。停止、换源和关闭窗口会取消当前会话。

检测为中文的内容跳过翻译。三个入口共用翻译模型和译文字号。鼠标移入半透明浮层时，右上方显示复制、停止和关闭图标。托盘左击和右击打开同一菜单。开启功能时预加载，切换模型、托盘手动释放、退出或空闲到期时释放模型。

软件架构与类图

Translator.Desktop 持有 UI 与会话生命周期。Translator.Core 定义数据、服务契约和 OCR／字幕调度。Translator.Platform.Windows 提供 Windows 采集与设备发现。Translator.Inference 实现 PaddleOCR、Whisper、Nemotron、Qwen3-ASR、可选说话者分段和 llama.cpp 客户端。

控制器持有独立的选区和 OCR 浮层。AudioSubtitleWindow 由每次音频会话创建。SettingsStore 分别保存用户偏好和两种长期窗口的位置。

时序图

DXGI 先用脏矩形和移动矩形过滤选框外更新，再只读回选框。旋转屏幕和 DXGI 不可用的会话回退到 GDI。选区、OCR 与即时字幕共用流式翻译接口，llama.cpp 适配器通过 SSE 输出累计译文。段落修订读取结构化的完整响应。

llama.cpp 按 token 前缀复用单槽中的可用状态。前缀变化的部分重新计算。GPU 默认先选 CUDA，之后可尝试已安装的 Vulkan，CPU 回退由设置控制。子进程仅监听本机环回地址并使用每次启动生成的密钥。

配置与模型

文件内容
translator.runtime.json应用内置推理预算、显存和进程时限、OCR 和 DXGI 等待时间、字幕队列、Whisper 分段和设备参数，可通过本机高级配置覆盖。
scripts/setup-runtime.ps1下载和校验固定版本的 CUDA／Vulkan、PaddleOCR、Whisper，以及选装的 ONNX 转写模型和说话者分段组件。
translater.local.json 或用户设置翻译模型目录、所选文件、转写后端及模型目录、说话者标注、语种、GPU 与 CPU 回退、快捷键和译文字号。设置和模型路径保存在本机。
overlay-positions.jsonOCR 与音频窗的独立位置。恢复时按当前屏幕工作区约束窗口位置。

首次运行时在设置页选择模型目录和 GGUF 文件，选择结果保存在本机。高级调优可在本机数据目录放置完整的 translator.runtime.json，或通过 TRANSLATOR_CONFIG_PATH 指定文件。配置无效时显示原因并使用内置默认值。

推荐 Qwen3.5-9B Q4_K_M，显存较小时可选 Qwen3.5-4B Q4_K_M。翻译模型目录应包含可读取的 GGUF 文件。显存由所选权重、上下文缓存和计算缓冲共同决定。

移植边界与验证

Windows 首版使用 UI Automation、DXGI/GDI、WASAPI Process Loopback 和 Windows 托盘。macOS 与 Linux 可以在相同契约下提供选区、选框采集、程序音频及推理运行时适配器。平台 UI 和权限交互也在各自的宿主层实现。

  • 运行 dotnet build -c Release 并检查 --check-models 的模型和设备候选。
  • 手动覆盖静态 PDF、持续滚动、切换屏幕、OCR 空白复核、选区重定位及窗口恢复。
  • 使用所选程序播放英日音频，验证即时字幕、段落修订和关闭后的资源释放。
