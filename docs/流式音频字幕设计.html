流式音频字幕设计

记录 Windows 程序音频到双层本地译文的实现和调度边界。

技术方案与时序采集和转写字幕与修订验收

采集和转写

托盘列出可选择的应用程序。通过 IApplicationAudioCapture 获取所选进程树的音频，转换为 16 kHz 单声道 PCM。Windows 实现为 ProcessLoopbackCapture。停止或更换程序时，旧会话取消并回收采集资源。

WhisperSpeechTranscriber 按能量、句尾静音和最长块时限切分音频，逐块提交带起止时间和语种的结果。前置样本、静音阈值和分段时长由运行配置控制。

即时层和修订层

  1. 短句进入有界队列，队列满时优先保留新句。过期句和中文跳过。即时请求携带最近几条已确认原文，并在同一行 ID 上合并 SSE 片段。
  2. 相邻短句满足行数和间隔时，字幕会话尝试空档修订。请求使用原文和行 ID，返回结构化逐行译文。有效结果替换原行。
  3. 新短句到达时取消正在等候或生成的修订。修订超时或失败时保留已显示译文。模型驻留和串行调度由 LlamaTranslator 统一负责。
  4. 字幕窗支持滚动、双语显示和标题栏拖动。位置单独保存，关闭或更换程序后在上次位置恢复。

验收用例

  • 同时播放两个程序，检查只有所选进程树的声音进入字幕。
  • 在英日片段之间加入静音，检查短句出现和空档段落修订。
  • 修订期间继续发声，检查新短句优先以及旧 ID 的译文不会写入别处。
  • 拖动后停止并重开字幕，检查恢复位置和滚动。
