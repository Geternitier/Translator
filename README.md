# Translator

Translator 是一款本地翻译工具，支持英语、日语到简体中文。

- **选区翻译**。选中文字后，译文在选区旁出现。可以复制、关闭或拖动当前浮层。
- **持续 OCR**。框选屏幕区域，内容变化时更新译文。选框可拖动、缩放和暂停。
- **音频字幕**。选择要翻译的程序。字幕流式显示，空档时按段落修订。

程序跳过检测为中文的内容。三个功能使用设置里选定的同一个 GGUF 模型。推荐 Qwen3.5-9B Q4_K_M，显存较小时可选 Qwen3.5-4B Q4_K_M。
