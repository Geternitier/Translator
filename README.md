# Translator

Translator 是一款本地翻译工具，支持英语、日语到简体中文。

- **选区翻译**。选中文字后，译文在选区旁逐步显示。可以复制、停止、关闭或拖动浮层。
- **持续 OCR**。框选屏幕区域，内容变化时流式更新译文。选框可拖动、缩放和暂停。
- **音频字幕**。选择音频程序和转写后端。字幕流式显示，空档时按段落修订，并可显示说话者编号。

程序跳过检测为中文的内容。三个功能共用同一个 GGUF 翻译模型、浮窗字号和悬停工具栏。推荐 Qwen3.5-9B Q4_K_M，显存较小时可选 Qwen3.5-4B Q4_K_M。
